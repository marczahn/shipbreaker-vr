Second test build of the Hardspace: Shipbreaker VR mod (PC VR via OpenXR, tested with Quest 3 over Virtual Desktop).

## New
- World scale option (0.5 to 3): above 1 distant objects keep more stereo depth and sizes are easier to judge
- VR options moved to the Video tab (rows starting with "VR:" at the bottom), reachable with keyboard and gamepad,
  in the main menu and in the pause menu
- Render resolution is limited to what fits into the graphics card's memory; a value that does not fit is refused
  and the previous one stays

## Fixed
- Selection jumping back up when scrolling the options with the arrow keys while the mouse pointer rests over the list
- Out-of-memory crash when VR was switched on during a mission load: the render resolution now applies right at
  VR start, and the renderer's buffers shrink after VR is switched on or off or the resolution goes down
- Smearing image after setting a very high render resolution

## Licenses
The ZIP now contains the license texts of all bundled components (`BepInEx\plugins\ShipbreakerVR\licenses\`) and
`THIRD-PARTY-NOTICES.md`.

## Install
Download `ShipbreakerVR-0.7.0.zip`, extract everything into the folder that contains `Shipbreaker.exe` and start the
game. See [docs/INSTALL.md](../INSTALL.md) for details and uninstalling.
