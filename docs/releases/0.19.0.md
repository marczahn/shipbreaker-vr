Fourteenth test build of the Hardspace: Shipbreaker VR mod (PC VR via OpenXR, tested with Quest 3 over Virtual Desktop).
Alpha: expect rough edges.

## New
- A tether mode for the grapple, switched with B like the cutter's modes. The laser turns orange with a ring where it
  points, and the controller buzzes twice (once when grappling comes back). In the tether mode:
  - pull the trigger at the start of a tether and let go at the end; a line shows the tether meanwhile,
  - point at a tether (it lights up orange) and tap A to remove just that one,
  - hold A to recall all tethers,
  - B switches back to grappling however long you hold it, so a slow tap never recalls your tethers.

  Grappling works as before, including holding B to place or recall tethers.
- New control overviews, one per topic: flying, hands, tool buttons, cutter, demo charges, grapple and tethers, menus
  and keyboard. They are in the README and in [docs/INSTALL.md](../INSTALL.md), which now also explains holding on
  and climbing.
- The keys F3, F4, F7 and F8 can be changed in the config file, section `[Tasten]`.

## Changed
- A (or X) uses what you point at from either hand, also an empty one, which uses what you look at. The grip no longer works airlock consoles and
  switches; it holds on there too, like everywhere else.
- When Virtual Desktop or the headset disconnects, VR stops after a few seconds and the game shows the flat view
  again; the game keeps running instead of quitting.
- Numbers edited by hand into the config file are kept within their allowed range.

## Fixed
- Right after a tool changed hands, the aim, the laser and the cutter's line could come from the previous hand for a
  frame.

## Known issues
- Holding something heavy with the game's own grab still stops thrust, as in the flat game.
- The cutter's switch between horizontal and vertical cuts has no button; roll your wrist instead. The part at the
  front of the cutter that shows the angle therefore always stands crosswise.
- Holding A in the grapple's tether mode while looking at a console uses the console and then recalls your tethers.
- The spots on the body for the tools are a first guess and may need getting used to.
- During load screens the view can still go dark for a blink.
- There is no button for the gamepad's View button, and the left menu button stays with Virtual Desktop.
- Render resolutions above 1.0x can run out of video memory right after loading into a shift, which crashes the game.
  If that happens, lower "Render resolution" to 1.0.

## Install
Download `ShipbreakerVR-0.19.0.zip`, extract everything into the folder that contains `Shipbreaker.exe` and start the
game. See [docs/INSTALL.md](../INSTALL.md) for details and uninstalling. If you update from an earlier version, your
settings stay.
