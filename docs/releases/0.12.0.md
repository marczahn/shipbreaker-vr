Seventh test build of the Hardspace: Shipbreaker VR mod (PC VR via OpenXR, tested with Quest 3 over Virtual Desktop).
Alpha: expect rough edges.

## New
- Menus work with the motion controllers. In menus both controllers act as one Xbox gamepad, each button where its
  counterpart sits, and the game shows its gamepad button prompts:
  - sticks = sticks (left stick navigates, right stick scrolls),
  - A/B/X/Y = A/B/X/Y (A confirms, B goes back),
  - triggers = shoulder buttons (switch tabs), grips = triggers,
  - pressing the left stick = Start: in gameplay it opens the pause menu, on loading screens it cycles the tips.
- "Center view" at the top of the VR tab does the same as F4, so recentering no longer needs the keyboard.
- The right stick's snap turn pauses while a menu is open.

## Known issues
- With controller flying, pressing the left stick still brakes, so braking also opens the pause menu. The next version
  moves the brake to Y.
- There is no button for the gamepad's View button, and the left menu button stays with Virtual Desktop.
- Tools are still aimed with the head, not with the hands.
- Render resolutions above 1.0x can run out of video memory right after loading into a shift, which crashes the game.
  If that happens, lower "Render resolution" to 1.0.

## Install
Download `ShipbreakerVR-0.12.0.zip`, extract everything into the folder that contains `Shipbreaker.exe` and start the
game. See [docs/INSTALL.md](../INSTALL.md) for details and uninstalling.
