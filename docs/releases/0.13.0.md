Eighth test build of the Hardspace: Shipbreaker VR mod (PC VR via OpenXR, tested with Quest 3 over Virtual Desktop).
Alpha: expect rough edges.

## New
- Controller flying turns and pitches with the left stick: left/right turns, up/down pitches (stick up looks up), the
  further, the faster. No trigger needed. Thrust (hold the trigger and move the controller) and rolling (tilt it
  sideways with the trigger held) stay as they were.
- New VR tab row "Turning": smooth, or steps of 30, 45 or 90 degrees per flick of the left stick.
- Y brakes.
- Pressing X and A together opens the pause menu in gameplay and cycles the tips on loading screens.
- A controls overview image in README and INSTALL.

## Changed
- Turning and pitching by twisting the controller are gone; so is the fixed snap turn on the right stick.
- Pressing the left stick no longer brakes or pauses, so steering with it can't set either off by accident.

## Fixed
- Braking no longer opens the pause menu (known issue in 0.12.0).

## Known issues
- There is no button for the gamepad's View button, and the left menu button stays with Virtual Desktop.
- Tools are still aimed with the head, not with the hands.
- Render resolutions above 1.0x can run out of video memory right after loading into a shift, which crashes the game.
  If that happens, lower "Render resolution" to 1.0.

## Install
Download `ShipbreakerVR-0.13.0.zip`, extract everything into the folder that contains `Shipbreaker.exe` and start the
game. See [docs/INSTALL.md](../INSTALL.md) for details and uninstalling.
