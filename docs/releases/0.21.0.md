Sixteenth test build of the Hardspace: Shipbreaker VR mod (PC VR via OpenXR, tested with Quest 3 over Virtual Desktop).
Alpha: expect rough edges.

## New
- Alternate eyes (VR options, "Alternate eyes", on by default, F11): each picture draws only one eye, the left and the
  right in turn; the other eye shows its last picture, turned to where you look now. In the bay the processor, not
  the graphics card, limits the frame rate, and half of its rendering work is per eye. In our test in a busy bay the
  frame rate rose from 54 to 63 fps and missed frames at 90 Hz fell from 100 % to 24 %. Fast-moving things can flicker
  slightly, because the eyes see them at different moments; switch it off if that bothers you.
- The performance display shows "alternate eyes" while they are on.

## Known issues
- Holding something heavy with the game's own grab still stops thrust, as in the flat game.
- In the cutter's Stinger mode A does nothing.
- Holding A in the grapple's tether mode while looking at a console uses the console and then recalls your tethers.
- The spots on the body for the tools are a first guess and may need getting used to.
- During load screens the view can still go dark for a blink.
- There is no button for the gamepad's View button, and the left menu button stays with Virtual Desktop.
- Render resolutions above 1.0x can run out of video memory right after loading into a shift, which crashes the game.
  If that happens, lower "Render resolution" to 1.0.

## Install
Download `ShipbreakerVR-0.21.0.zip`, extract everything into the folder that contains `Shipbreaker.exe` and start the
game. See [docs/INSTALL.md](../INSTALL.md) for details and uninstalling. If you update from an earlier version, your
settings stay.
